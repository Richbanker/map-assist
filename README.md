# Map Assist 🗺️


[![Просмотры README](https://vbr.nathanchung.dev/badge?page_id=Richbanker.map-assist&text=README_Views)](https://github.com/Richbanker/map-assist)

Интерактивное веб-приложение для работы с картами и управления местами. Позволяет находить, сохранять и управлять интересными местами на карте.

## 📋 Описание

Map Assist - это современное React приложение, которое позволяет пользователям:
- 🗺️ Просматривать места на интерактивной карте
- 🔍 Фильтровать места по различным критериям
- ❤️ Добавлять места в избранное
- 📖 Просматривать детальную информацию о местах
- 📱 Управлять списком избранных мест
- 📍 Определять свое местоположение
- 🔎 Искать места через внешние API

## 🛠️ Технологический стек

### Frontend
- **React 18** - основная библиотека для UI с новейшими возможностями
- **TypeScript** - строгая типизация для надежности кода

### Тестирование
- **Jest** - тестовый фреймворк

- **@testing-library/jest-dom** - дополнительные матчеры для Jest

### Разработка
- **ESLint** - линтинг кода
- **PostCSS** - обработка CSS
- **Autoprefixer** - автоматические CSS префиксы

## 🚀 Установка и запуск

### Предварительные требования
- Node.js 16+ 
- npm или yarn

### Установка

1. **Клонируйте репозиторий:**
```bash
git clone <repository-url>
cd map-assist
```

2. **Установите зависимости:**
```bash
npm install
```

3. **Запустите проект в режиме разработки:**
```bash
npm run dev
```

4. **Откройте браузер и перейдите по адресу:**
```
http://localhost:5173
```

### Дополнительные команды

```bash
# Сборка для продакшена
npm run build

# Предварительный просмотр продакшн сборки
npm run preview
```

## 📖 Инструкция по использованию

### 🗺️ Основная карта

**Навигация по карте:**
- Перемещение: перетаскивание мышью
- Масштабирование: колесо мыши или кнопки +/- 
- Двойной клик: увеличение масштаба

**Работа с маркерами:**
- Клик по маркеру: открытие попапа с информацией
- В попапе: кнопка "Подробнее" для перехода на страницу места
- Кнопка сердца: добавление/удаление из избранного

### 🔍 Поиск и фильтрация

**Панель фильтров (левая сторона):**
- **Поиск**: введите название, адрес или описание места
- **Категория**: выберите тип места (ресторан, кафе, магазин и т.д.)
- **Рейтинг**: установите минимальный рейтинг
- **Радиус**: настройте радиус поиска в километрах
- **Теги**: выберите интересующие теги

**Кнопки управления:**
- 🔄 Сброс фильтров: очистить все фильтры
- 📍 Моё местоположение: определить и показать вашу позицию

### ❤️ Избранное

**Добавление в избранное:**
- Через попап маркера на карте
- Через кнопку сердца на карточке места
- Через детальную страницу места

**Управление избранным:**
- Переход на страницу "Избранное" через меню
- Просмотр всех избранных мест
- Удаление из избранного
- Очистка всего списка

## 🔧 Разработка

### Структура данных

**Place (Место):**
```typescript
interface Place {
  id: string;                    // Уникальный идентификатор
  name: string;                  // Название места
  description: string;           // Описание
  category: PlaceCategory;       // Категория
  coordinates: [number, number]; // Координаты [широта, долгота]
  address: string;               // Адрес
  rating: number;                // Рейтинг (0-5)
  isFavorite: boolean;           // В избранном
  images: string[];              // Массив URL изображений
  tags: string[];                // Теги
  createdAt: string;             // Дата создания
  updatedAt: string;             // Дата обновления
}
```

**Filter (Фильтр):**
```typescript
interface Filter {
  category?: PlaceCategory;      // Категория
  rating?: number;               // Минимальный рейтинг
  tags?: string[];               // Теги
  searchQuery?: string;          // Поисковый запрос
  radius?: number;               // Радиус поиска в км
}
```

### Управление состоянием

Приложение использует Zustand для управления состоянием:

- **usePlacesStore** - управление списком мест, поиск, CRUD операции
- **useFiltersStore** - управление активными фильтрами
- **useFavoritesStore** - управление избранными местами (с persist в localStorage)

### API интеграции

- **Nominatim API** - поиск мест через OpenStreetMap
- **Geolocation API** - определение местоположения пользователя
- **LocalStorage** - сохранение избранных мест
